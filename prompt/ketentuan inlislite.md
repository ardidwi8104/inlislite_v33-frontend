Seluruh perpustakaan lembaga ataupun perorangan yang membutuhkan aplikasi INLIS Lite dipersilahkan untuk mengunduh, menginstalasi, dan memanfaatkan aplikasi INLIS Lite.
Seluruh perpustakaan lembaga ataupun perorangan dipersilahkan untuk menyalin dan menginstalasi komponen perbaikan program (patch) dan komponen pemutakhiran (update) apabila tersedia.
Dilarang memperjual belikan paket instalasi dan update komponen perbaikan (patch), ataupun komponen pemutakhiran (update) INLIS Lite.
Dukungan Teknis (Technical Support) dan Bimbingan Teknis akan diberikan oleh Perpustakaan Nasional Republik Indonesia selama memenuhi syarat dan ketentuan yang berlaku.
Perpustakaan Nasional Republik Indonesia merekomendasikan kepada Perpustakaan Umum Pemerintah Propinsi/Kabupaten/Kota sebagai pembina perpustakaan di wilayahnya untuk berperan aktif membantu memberikan dukungan teknis.
Semua pihak dengan tujuan yang baik dipersilahkan untuk berkontribusi dengan cara memodifikasi beberapa tampilan dan/atau beberapa fungsi program di dalam perangkat lunak aplikasi INLIS Lite Versi 3 PHP (Opensource) dengan memperhatikan semua poin-poin yang ada di dalam ketentuan berikut:
1. Tidak diperkenankan untuk menghapus logo dan tulisan INLIS Lite di modul dan/atau laman apapun.
2. Tidak diperkenankan untuk menghapus dan/atau mengubah kalimat yang berisi Hak Cipta © Perpustakaan Nasional Republik Indonesia.
3. Tidak diperkenankan untuk mengubah meta data MARC yang menjadi ciri utama dari pembentukan katalog digital dalam perangkat lunak program aplikasi INLIS Lite.
4. Semua pihak yang melakukan modifikasi program aplikasi INLIS Lite bersedia membagi source code hasil kegiatan tersebut secara penuh kepada Perpustakaan Nasional RI.
5. Tidak diperkenankan memperjualbelikan source code / program aplikasi INLIS Lite dan hasil modifikasinya.
